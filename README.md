# cardputer-fm1

An M-VAVE **FM-1**–class six-operator FM synthesizer, built to run on the **M5Stack
Cardputer ADV** (ESP32-S3, 240 MHz, 512 KB SRAM, no PSRAM).

The FM-1 runs a JieLi AC791N (pi32v2) with a stripped proprietary engine, so its binary
cannot be ported. What *is* portable is the instrument: the DX7 voice model, the 32
algorithms, the factory bank and the panel/MIDI contract. Those are published, and this
project implements them.

**Status: engine and voice formats complete and gated. No firmware on hardware yet.**

## What is verified right now

| Gate | Result |
|---|---|
| Engine bit-exactness vs upstream msfa (Apache-2.0), 44.1 kHz | **606,720 samples, 0 mismatches** — 32 algorithms × feedback 1–7, velocities 1–127, notes 0–127, release from every envelope stage, 6 LFO waveforms with PMD/AMD, pitch envelope, pitch bend, block boundaries |
| Lookup tables | generated by compiling msfa's own `Sin::init`/`Exp2::init`/`Freqlut::init`, not re-derived; hash-gated |
| Factory bank | 128 voices, sha256 `ecad0b86…6aad25` = the hash M-VAVE publishes |
| Voice formats | 156-byte patch, 128-byte bank record, VCED, VMEM, FM-1 single-parameter SysEx — all round-trip tested |

The stock FM-1 firmware carries **msfa's 32-row algorithm table verbatim** at
`app.bin` offset `0x8BE8C` (V15) / `0x406FC` (V16) — verified by memcmp against upstream
`fm_core.cc`. That is why msfa is the fidelity target rather than a lookalike.

## Layout

```
components/fmengine/    portable engine: no IDF, no libc beyond memcpy
  include/fm_engine.h   6-op FM voice model, msfa layout
  include/fm_bank.h     factory bank, DX7 + FM-1 SysEx
  include/fm_tables.h   table declarations
  src/fm_engine.c       the port (env, pitch env, LFO, kernels, algorithms, note setup)
  src/fm_tables.c       generated tables
  src/fm_bank.c         bank + SysEx codecs
  src/fm_bank_data.c    128 factory voices
test/host/              bit-exactness + format gates
tools/                  table generator, host test runner, msfa fetch
firmware/               ESP-IDF app (bring-up next; needs hardware)
docs/                   design notes
```

## Build the gates

```sh
tools/fetch_msfa.sh          # vendor the Apache-2.0 reference (not committed)
tools/run_host_tests.sh      # bit-exactness + bank/SysEx
```

Requires `cc` and `c++`. No ESP toolchain for the host gates.
